# EmpireCodes Staff Admin App (App 2)

Dedicated operational dashboard for EmpireCodes engineering staff and client managers.

## Features
- **Passcode Gate**: Enter staff passcode `2026` to unlock.
- **Lead Pipeline**: View incoming Contact Us inquiries. 1-tap WhatsApp direct chat, call client, update lead status.
- **Contract Orders Desk**: Track client contracts, advance status (`accepted`, `in_progress`, `audit`, `completed`).
- **Live Two-Way Contract Chat**: Direct iMessage-style communication with clients under their booked contracts.
- **Review Moderation**: Approve or revoke client feedback before publishing to the live website.
- **Microservices API Host**: Switch between Render Cloud and Local laptop.

## Running Locally
```bash
cd empirecodes_staff_admin_app
npm install
npx expo start
```
